# The 5 Pillars of a Second Brain

| Pillar | In Maestro | Question it answers |
|---|---|---|
| 1. Interaction layer | Dashboard chat, voice, Claude Desktop | How do I talk to it? |
| 2. AI reasoning engine | Claude (default), ChatGPT, Gemini, Hermes | Who thinks? |
| 3. Integration layer | MCP connectors: email, calendars, Slack, texts, calls, role tools | What can it see and do? |
| 4. Knowledge sources | This Obsidian vault | What does it know? |
| 5. Memory protocol | [[About Me]], [[Preferences]], [[Memory Log]], [[Memory Protocol]] | What does it remember about me? |

A **chatbot** has pillars 1–2. A **second brain** has all five. An **autonomous agent** adds goals and the permission to act on its own. See [[Reactive vs Proactive]].
