# Skills Library

Skills are reusable playbooks. Each one is a Markdown note with a `description` and `triggers`. Maestro runs a skill when your message matches a trigger, Claude Desktop sees each skill as a prompt (the **+** menu), and you can export them as Claude Skills from the dashboard.
