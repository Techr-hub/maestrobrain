# 🧠 Maestro Home

Welcome to your second brain. This vault is the **knowledge layer** of Maestro. Everything here is plain Markdown, so it is yours forever, works in [Obsidian](https://obsidian.md), and is readable by Claude through the Maestro MCP server.

## The 5 pillars
1. **Interaction layer**: the Maestro dashboard (chat + voice) and Claude Desktop. See [[The 5 Pillars]].
2. **AI reasoning engine**: Claude by default; ChatGPT, Gemini or Hermes can plug in.
3. **Integration layer (MCP)**: email, calendars, Slack, texts, calls, plus role tools.
4. **Knowledge sources**: this vault: [[Projects Index]], [[People Index]], [[Decision Log]].
5. **Memory protocol**: [[About Me]], [[Preferences]], [[Memory Log]], rules in [[Memory Protocol]].

## Folders
| Folder | What goes there |
|---|---|
| `Memory/` | Facts the brain should always know about you |
| `Projects/` | One note per project, linked to people and decisions |
| `People/` | One note per person you work with |
| `Meetings/` | Meeting notes and prep |
| `Decisions/` | Why things were decided |
| `Tasks/` | Checkbox tasks (`- [ ]`) the brain can read and tick off |
| `Daily/` | Daily notes, morning briefs and the brain log |
| `Agents/` | Specialist agents (`@handle`) as Markdown |
| `Skills/` | Reusable playbooks the brain can run |
| `Personal/` | Personal profile notes (only used in Personal mode) |
| `Inbox/` | Answers and captures saved from chat |
