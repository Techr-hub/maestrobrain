# Stakeholder Update

1. Run [[Sprint Briefing]] first if sprint data is needed.
2. Write 4 sentences: **status**, **main risk**, **plan**, **decision needed (with deadline)**.
3. Match the reader: check `People/` for how they like updates (e.g. [[Priya Shah]] wants one-pagers).
4. Offer to save to `Inbox/` and add a task to send it.
