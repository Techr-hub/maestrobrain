# Sprint Briefing

1. Get sprint issues from Linear/Jira (`get_feed source=linear` / `jira`) and read the current sprint note (e.g. [[Sprint 24]]).
2. Report progress: points done / committed, days left, % complete.
3. List blockers with owner, impact and what unblocks them.
4. List risks from the sprint note.
5. Recommend 3 next steps, each with an owner.
