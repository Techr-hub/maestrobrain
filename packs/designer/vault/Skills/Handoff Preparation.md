# Handoff Preparation

1. Collect unresolved Figma comments and open feedback (e.g. [[Checkout v3]] → Open feedback).
2. List the changes needed before handoff, each with owner and component/state.
3. Run the checklist: all states designed, tokens mapped, redlines exported, edge cases documented, open comments resolved.
4. Draft a handoff note for engineering.
