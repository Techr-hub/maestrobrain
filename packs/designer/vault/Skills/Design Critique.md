# Design Critique

1. Read the project note and Figma comments from the feed.
2. Evaluate: goal fit, hierarchy, consistency with the design system, accessibility (contrast, targets, focus), states.
3. Output by severity: Blocking, Should fix, Nice to have. Name component + state for each.
